# Module Eight: Relations and Recursion

The Python program models Problems 1–16 with finite examples, counterexamples,
recursive functions, and complexity measurements. The notebook presents the
same work in sections suitable for screenshots.

## Run

```bash
python3 cs505_relations_recursion_models.py
```

Keep the notebook and Python file in the same directory. Matplotlib is optional;
when available, the program generates modulo-6 and recursive-space figures.
Computed examples support the written proofs but do not replace general proofs.
