# SNHU Coursework Programs

Runnable programs and computational models organized by course.

## Courses

- `CS-505`
  - Module Eight relations, functions, equivalence classes, recursion, and complexity models
- `CS-508`
  - Directed graph representations in Java
  - Weighted graph traversal and shortest-path models in Python/Jupyter
  - Project Two electric-vehicle database in Java

Each project folder contains its own instructions. Generated images, reports,
compiled classes, and notebook checkpoints are intentionally excluded from Git.
