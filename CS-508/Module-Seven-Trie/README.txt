PYCHARM INSTRUCTIONS

1. Open the trie_pycharm folder as a PyCharm project.
2. Open PyCharm's Terminal at the bottom of the screen.
3. Enter: pip install -r requirements.txt
4. Open trie_diagram.py.
5. Click the green Run button.
6. Open the trie_outputs folder.

Use trie_diagram.png in the Word assignment. It is exported at 300 DPI.
The SVG stays sharp at any size, and the PDF is useful for printing.

Green nodes with a star are complete words. Blue nodes are shared prefixes.
