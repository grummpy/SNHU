# Module Eight: Graph Traversal

Models two supplied weighted graphs and reports:

- adjacency lists and weighted adjacency matrices
- shortest and longest simple paths
- breadth-first and depth-first traversal
- Dijkstra shortest paths
- Bellman–Ford shortest paths and negative-cycle checks

## Run

```bash
python3 cs508_graph_model.py
```

Keep the notebook and Python files in the same directory. Matplotlib is optional
and is used only for saved graph and matrix images.
