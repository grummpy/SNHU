# Project Two: EV Database

An in-memory Java database for the supplied electric-vehicle CSV data. It uses
an index by state for repeated searches and includes correctness/performance
tests.

## Compile and test

```bash
javac *.java
java EVDatabaseTest /path/to/CS_508_Project_Two_Data_Set.csv
```

Run the application with the course CSV path:

```bash
java Main /path/to/CS_508_Project_Two_Data_Set.csv
```

The course data file is not included in this repository.
